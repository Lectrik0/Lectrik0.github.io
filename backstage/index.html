Set up this device

Your GitHub token is encrypted with your password and stored only in this browser. The password itself is never stored or sent anywhere.

GitHub shows it when you make the token. Backstage reminds you before it runs out.
How to make the token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → Lectrik0.github.io.
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Pick an expiry (90 days is a good balance), generate, and paste it here.
